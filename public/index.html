Maya Friends backend

This site hosts the repository for the Maya Friends API gateway and its services. The Express services themselves are not served from this deploy — they run as standalone Node processes.

  • Auth service
    /api/auth · /api/user · /api/admin · /api/plan · /api/payments · /api/subscriptions
  • Chat service
    /api/friends · /api/chats · /api/messages · /api/groups
  • Post service
    /api/post
API gateway proxies these routes and serves Swagger docs at /api-docs.
